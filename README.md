# CypressUsingTs

Cypress ui test automation using typescript in pageObjectModel structure.

> this is a practice purpose repo could have incomplete components

## Install

```
git clone https://github.com/pritesh-git/cypressUsingTS.git
cd cypressUsingTS
npm i
```

### Run on browser

```
npm run cy:open
```

### Run Headless

```
npm run cy:run
```
